STL file

Design

The common 3D file format sent to a printer. It describes a part's surface as a mesh of triangles.

STL is the most widely used file format for 3D printing. It stores the outer surface of a part as a mesh of small triangles, without color or design history.

STL files work well for printing but are hard to edit. For changes, a native CAD file or a STEP file is better.

If you already have a file for your part, send it. We'll check it, fix problems, and confirm it's printable.
