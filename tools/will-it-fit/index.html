Will it fit?

Pick two things you want to connect: a vac, hose, tool port or accessory. We compare their sizes from our size data and tell you whether they should connect directly or need an adapter.

Use this often? Bookmark it so it's one click away next time.

How to read the answer

Same nominal size means both are listed at the same size, so they usually connect. Brand locking ends (Lock-On, Pos-I-Lock and similar) may not lock to another brand's fitting, and friction fits can be loose. Different sizes means you need an adapter; the button opens the adapter builder with both sizes filled in.

Not in the list? Measure both ends with the inch–mm converter handy, or look it up in the hose size finder.
